## A. BlueMonkey標準ページとして組み込む（推奨）
1. BlueMonkeyの既存サイトでLP用のページを新規作成し、**できるだけ全幅・サイドバーなしのテンプレート**を選択します。既存サイトのヘッダー・フッターを使う想定で、LPパッケージにはそれらを重複して入れていません。
2. ページ設定の「個別設定 ＞ その他の<head>領域」に、`lp_page_head_css.html` の中身（styleタグごと）を貼り付けます。既存サイトの共通CSSへ不用意に追加しないでください。
3. `blue_monkey_blocks/` の `01_hero.html` 〜 `10_contact_intro.html` を**順番に別々のコンテンツブロック**で挿入します。BlueMonkeyのブロック編集の「HTMLソース編集」機能を使用してください。巨大なHTMLを1ブロックへ入れると編集画面が崩れる場合があります。
4. `10_contact_intro.html` のすぐ後ろに新しい「スクリプト埋め込みブロック」を作成します。BowNowで生成した**本物の「サイト反映コード」全体**を、`11_bownow_script_block_PASTE_CODE_HERE.html` の `BOWNOW_SITE_REFLECTION_CODE_HERE` と書いた箇所に貼り、できた内容をそのスクリプト埋め込みブロックへ貼ります。実際のBowNowコードはコメントにせずそのまま入れてください。フォームが縦横に崩れる場合、ラッパーやBowNow側のフォームCSSを調整します。
5. スマホ下部の赤い固定CTAが必要なら、`12_optional_sticky_cta.html` を追加します。既存テンプレートに追従CTAがあるなら重複するので省略してください。
6. ページを保存→再構築して公開画面で確認してください。管理画面のプレビューでは**スクリプト埋め込みブロックは動作しない**場合があります。

### BowNowフォームと計測の設定
- BowNow管理画面の **フォーム・ファイル ＞ フォームを管理する** → 対象フォームの「サイト反映コード」→「サイト反映コードをコピー」。※フォームの設問・確認画面・個人情報の取扱い表示・送信完了後の動作はBowNow側で調整。
- トラッキングコードがサイトに未設置なら、BlueMonkey管理画面の **設定 ＞ サイト内共通設定 ＞ Google Analytics** にBowNowが発行したコードを設置して保存。共通設定は即時反映されるため、既存コードや二重設置を確認。
- 掲載ドメインがBowNowで許可・登録されているか確認。公開URLが確定したら実ドメインでフォームの表示と送信をテストしてください。
- **設定 ＞ BowNow設定** にあるトラッキングID/APIキーを入力する手順は主にBowNowログイン認証用です。今回の一般的な問い合わせフォーム埋め込みには必須と誤認しないでください。APIキーをLPのHTMLに記載しないこと。

## B. 既存HTMLをほぼそのまま公開する方法（BlueMonkeyオプション）
BlueMonkeyの**ユーザーディレクトリ機能**は、外部で作成したHTML等のアップロードに対応しています。ただし別途契約・設定が必要です。使用できる場合は `lp_user_directory_INSERT_BOWNOW_CODE.html` のプレースホルダーにBowNowの実コードを貼り込み、BlueMonkeyで指定されたディレクトリにアップロードしてください。運用方法はサイトの契約・制限に依存します。

## 共有
- `lp_share_preview.html` はデザイン・コピー確認用。画像はHTMLへ埋め込まれており単体で開けます。フォームは説明用プレースホルダーで送信されません。
- `*.html` および CSS は本パッケージ内のため社内の制作担当にZIPを配布できます。
- 不特定多数がアクセスできる公開URLは、CMSに配置・公開して初めて発行されます。このZIPそのものに公開URLはありません。

## 本番前の必須確認
- BowNowのフォームで「会社名」「担当者名」「メールアドレス」「採用したい拠点・相談内容」を準備（必要であれば電話、同意チェック）。
- フォームのプライバシーポリシー、確認画面、通知先、サンクスページ、二重送信防止、通知メールをチェック。
- LPの問い合わせ・資料DLリンク、既存サイト共通メニュー、料金表の税抜表記（販売価格の起点と課金単位）を確認。
- 実ドメインでスマホ/PCの外観、計測タグ、フォーム表示・実送信、BowNowのリード登録と通知を確認。
